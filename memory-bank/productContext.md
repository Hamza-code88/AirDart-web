# Product Context - AirDart Web

## Target Audience & Personas
1. **Desktop / Laptop Workstation Users:** Instant PC-to-Mobile and Mobile-to-PC local file exchange without cables or cloud uploads.
2. **Ad-hoc Guest Devices:** Any friend or colleague who does not have the native mobile app installed can scan a pairing QR code with their standard mobile camera to launch this web app and transfer immediately.
3. **Clipboard Sync Users:** Seamless text, URL, and code sharing between desktop browsers and mobile devices.

## UX & Design Standards
- Modern, high-performance UI using Tailwind CSS v4, Lucide icons, glassmorphic cards, and sleek dark mode.
- Interactive radar / nearby peer display.
- Drag-and-drop file dropzone with chunked streaming progress bar, live speed indicator (MB/s), and instant download triggers.
